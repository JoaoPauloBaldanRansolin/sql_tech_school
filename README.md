# 🎓 Tech School - Banco de Dados Relacional (PostgreSQL)

Este repositório contém a solução completa para o **Trabalho Prático Final: Arquiteto de Dados**, cobrindo modelagem relacional, integridade referencial, consultas avançadas com JOINs, triggers de auditoria em PL/pgSQL e views.

---

## Requisito Obrigatório: PostgreSQL

> **ATENÇÃO:** Este projeto foi projetado e otimizado especificamente para **PostgreSQL**. O script SQL utiliza funcionalidades nativas e sintaxe própria do Postgres, **não sendo compatível com MySQL, MariaDB ou SQL Server** sem modificações profundas.

---

##  Pré-requisitos

Para rodar este projeto, você precisa ter instalado:

* **PostgreSQL** (Eu usei a Versão 10.0)
---

## Pra executar:

### Opção 1: Via pgAdmin

1. Conecte-se ao servidor PostgreSQL.
2. Crie um banco de dados chamado `tech_school`:
   CREATE DATABASE tech_school;
3. Abra a ferramenta de execução de SQL (Query Tool ou SQL Editor) dentro do banco tech_school.
4. Copie o código contido no arquivo script_tech_school_postgres.sql e cole no editor.
5. Execute o script completo (Atalho: F5 ou botão Execute).
